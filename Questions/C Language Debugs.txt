Easy

Q1.
//what will be the output of the following.
#include <stdio.h>
int main() {
    int a = 10;
    printf("%d", a);
    return 0;
}

A)a
B)10
C)%d
D)Error

Answer B
printf("%d", a);`prints the value stored in the variable`a`. Here, `a`is an integer variable with value`10`. The format specifier `%d`is specifically used in C to display integer values. When the program runs,`printf()`replaces`%d`with the actual value of`a`, so the output becomes `10`.

Q4.
Required output "10"
#include <stdio.h>
int main() {
    int a = 5, b = 2;
    printf("%d", a ^ b);
    return 0;
}

A)%
B)*
C)/
D)+

Answer B
The operator ^ in C is not used for multiplication; it is the bitwise XOR operator. If the programmer wants to multiply two numbers, the correct operator is *. Using ^ gives a completely different result because it performs bit-level operations instead of arithmetic multiplication.

Q1.
//What will be output?
#include <stdio.h>
void show() {
    printf("Hello ");
}
int main() {
    show();
    show();
    return 0;
}

A)Hello
B)Hello Hello
C)HelloHello
D)Error

Answer C
The function show() contains printf("Hello ");, which prints the text "Hello " whenever the function is called. Inside main(), the function is called two times using show(); show();. Since there is no newline between the calls, both outputs are printed continuously on the same line. Therefore, the final output becomes HelloHello.

Q2.
//Required Output 25
#include <stdio.h>
void square(int n) {
    return n * n;
}
int main() {
    printf("%d", square(5));
    return 0;
}

A)int square(int n)
B)float square(int n)
C)char square(int n)
D)double square(int n)

Answer A
The function square() returns the value n * n using the return statement. However, the function is declared with the return type void, which means the function should not return any value. This creates an error because a void function cannot send data back to the caller. Since n * n produces an integer value, the correct return type should be int. After changing it to int square(int n), the function correctly returns 25.

Q10.
//Required Output 15
#include <stdio.h>
void add() {
    int a = 5, b = 10;
}
int main() {
    printf("%d", a + b);
    return 0;
}

A)Move int a = 5, b = 10; inside main()
B)Replace printf with scanf
C)Use float instead of int
D)Remove the function add()

Answer A
Variables declared inside a function are called local variables and can only be used within that function. In the given program, a and b are declared inside add(), so they are not accessible inside main(). When printf("%d", a + b); tries to use them, the compiler gives an error because a and b are unknown in main(). Moving the variable declarations into main() makes them accessible where they are needed, allowing the program to correctly print 15.
